# 🚀 Quick Start - WebSocket & Voice Chat

## Быстрый старт

### 1. Установка зависимостей

```bash
cd frontend
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` в папке `frontend`:

```env
VITE_API_URL=http://localhost:8000
VITE_WS_URL=ws://localhost:8000/ws
VITE_DEBUG=true
```

### 3. Запуск приложения

```bash
npm run dev
```

### 4. Проверка интеграции

1. Откройте браузер на `http://localhost:5173`
2. Перейдите в раздел "Чат"
3. Проверьте статус подключения (должен быть "Подключено")
4. Отправьте текстовое сообщение
5. Попробуйте голосовую запись (нажмите на микрофон)

## 🔧 Тестирование функций

### WebSocket соединение

```javascript
// В консоли браузера
console.log('WebSocket connected:', window.wsConnected);
```

### Голосовые функции

1. Нажмите на кнопку микрофона
2. Разрешите доступ к микрофону
3. Произнесите сообщение
4. Дождитесь транскрипции и ответа

### Режимы чата

- **Ментор** 🧘 - Финансовые советы
- **Аналитик** 💼 - Анализ данных
- **Друг** 💬 - Неформальное общение
- **Технарь** 🤖 - Техническая поддержка

## 🐛 Устранение неполадок

### WebSocket не подключается

1. Проверьте, что backend сервер запущен на порту 8000
2. Убедитесь, что WebSocket endpoint доступен: `ws://localhost:8000/ws`
3. Проверьте консоль браузера на ошибки

### Голосовые функции не работают

1. Убедитесь, что браузер поддерживает WebRTC
2. Проверьте разрешения на доступ к микрофону
3. Убедитесь, что backend поддерживает аудио endpoints

### Ошибки в консоли

```javascript
// Включить подробное логирование
localStorage.setItem('debug', 'true');
```

## 📱 Мобильная версия

Для тестирования на мобильных устройствах:

1. Запустите dev сервер с доступом по сети:
```bash
npm run dev -- --host
```

2. Откройте на мобильном устройстве:
```
http://[YOUR_IP]:5173
```
